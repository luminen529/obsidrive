## ✨ 왜 ObsiDrive인가요?

|  |  |
|---|---|
| 🙈 **Drive를 어지럽히지 않아요** | Google Drive의 숨김 앱 폴더(`appDataFolder`)에 저장해서, "내 드라이브"에는 아무것도 보이지 않습니다. |
| 🔒 **꼭 필요한 권한만** | `drive.appdata` 권한 하나만 요청합니다. Drive에 있는 다른 파일은 읽을 수도, 쓸 수도 없어요. |
| 🚫 **중간 서버가 없어요** | 내가 만든 OAuth 클라이언트로 Google API와 직접 통신합니다. 인증 정보는 OS 키체인(Obsidian Secret Storage)에 안전하게 보관돼요. |
| 🧩 **설정까지 그대로** | 노트뿐 아니라 `.obsidian` 설정, 테마, 플러그인 코드와 설정까지 맞춰줍니다. |
| 🖥️📱 **데스크톱 & 모바일** | Obsidian 1.13.2 이상이면 어디서든 동작합니다. |

> [!NOTE]
> ObsiDrive는 아직 초기 버전(0.x)입니다. 처음 쓰실 때는 **볼트를 백업해 두거나 테스트용 볼트로 먼저** 써 보시길 권해요.

## 🚀 시작하기

ObsiDrive를 쓰려면 세 단계만 거치면 됩니다.

1. **플러그인 설치** — BRAT으로 설치하는 게 가장 간단해요.
2. **Google Cloud에서 OAuth 클라이언트 만들기** — 처음 한 번만 하면 됩니다.
3. **플러그인 설정에서 로그인하고 `지금 동기화`** — 끝!

### 1️⃣ 플러그인 설치

#### BRAT으로 설치 (권장 · 모바일 포함)

1. **설정 → 커뮤니티 플러그인**에서 **BRAT**(Obsidian42 - BRAT)를 설치하고 켭니다.
2. BRAT 설정에서 **Add beta plugin**을 누르고 `luminen529/obsidrive`를 입력합니다.
3. 커뮤니티 플러그인 목록에서 **ObsiDrive**를 켭니다.

새 버전이 [Releases](https://github.com/luminen529/obsidrive/releases)에 올라오면 BRAT이 알아서 업데이트해 줍니다.

> [!TIP]
> ObsiDrive는 자기 자신의 플러그인 폴더는 동기화하지 않아요. 기기마다 BRAT으로 설치해 두면 업데이트 걱정이 없습니다.

<details>
<summary><b>직접 빌드해서 설치하기</b></summary>

<br>

```bash
npm install
```

```bash
npm run build
```

`dist/` 폴더에 만들어진 `main.js`, `manifest.json`, `styles.css`를 볼트의 `.obsidian/plugins/obsidrive/` 폴더에 복사한 뒤, 커뮤니티 플러그인에서 켜면 됩니다.

</details>

### 2️⃣ Google Drive 연결 준비 (처음 한 번)

ObsiDrive는 중간 서버 없이 **내 Google Cloud 프로젝트의 OAuth 클라이언트**로 동작해요. 조금 번거롭지만 한 번만 해 두면 됩니다.

1. [Google Cloud Console](https://console.cloud.google.com/)에서 새 프로젝트를 만듭니다.
2. **API 및 서비스 → 라이브러리**에서 **Google Drive API**를 찾아 **사용**을 누릅니다.
3. **OAuth 동의 화면(Google 인증 플랫폼)** 을 설정합니다.
   - 사용자 유형은 **외부**, 범위(데이터 액세스)에는 `https://www.googleapis.com/auth/drive.appdata`를 추가합니다.
   - **대상**에서 **앱 게시**를 눌러 **프로덕션**으로 바꿔 주세요.
4. **클라이언트 → 클라이언트 만들기**에서 유형을 **데스크톱 앱**으로 선택하고, **Client ID**와 **Client Secret**을 복사해 둡니다.

> [!IMPORTANT]
> - 클라이언트 유형은 꼭 **데스크톱 앱**이어야 해요. 그래야 로그인 리디렉션(`127.0.0.1`)이 동작합니다.
> - 앱을 "테스트" 상태로 두면 로그인이 **7일마다 만료**돼요. 가능하면 프로덕션으로 게시하세요.
> - 로그인할 때 "확인되지 않은 앱" 경고가 나오면 **고급 → ObsiDrive(으)로 이동**을 누르면 됩니다. 내가 만든 앱이니 안심하셔도 돼요.

### 3️⃣ 로그인하고 첫 동기화

1. ObsiDrive 설정에 **Client ID**와 **Client Secret**을 붙여넣고 로그인합니다.
   - 🖥️ **데스크톱**: 브라우저에서 허용하면 자동으로 돌아옵니다.
   - 📱 **모바일**: 브라우저에서 허용한 뒤, 주소창의 리디렉션 URL을 복사해 설정에 붙여넣으면 됩니다.
2. 리본의 ↻ 아이콘이나 명령 팔레트에서 **ObsiDrive: 지금 동기화**를 실행합니다.

첫 동기화는 안전을 위해 **항상 직접 시작**해야 해요. 그 다음부터는 자동 동기화가 알아서 돌아갑니다. 🎉

## 📦 무엇을 동기화하나요?

| 항목 | 경로 | 기본값 |
|---|---|:---:|
| 📝 노트 · 첨부파일 | 볼트 전체 (점으로 시작하는 폴더 제외) | ✅ |
| ⚙️ Obsidian 설정 | `.obsidian/*.json` | ✅ |
| 🎨 테마 | `.obsidian/themes/*/` | ✅ |
| 💅 CSS 스니펫 | `.obsidian/snippets/*.css` | ✅ |
| 🧩 커뮤니티 플러그인 | `.obsidian/plugins/*/{main.js,manifest.json,styles.css}` | ✅ |
| 🔧 플러그인 설정 | `.obsidian/plugins/*/data.json` | ✅ |
| 🪟 워크스페이스 | `workspace.json`, `workspace-mobile.json` | ⬜ |

- 제외 패턴(glob 또는 `/정규식/`)과 최대 파일 크기도 설정에서 바꿀 수 있어요.
- ObsiDrive 자신의 폴더(설정, 동기화 상태)는 동기화하지 않습니다.
- **플러그인을 켜고 끄는 건 기기마다 따로예요.** 설치·업데이트·삭제는 동기화되지만, 활성화 목록(`community-plugins.json`)은 기기별로 둡니다. 모바일에서 플러그인을 꺼도 PC에서는 그대로 켜져 있어요.
  - 기기에서 처음 동기화할 때 동기화된 플러그인을 모두 켭니다.
  - 다른 기기에서 새로 설치한 플러그인은 내려받으면서 자동으로 켜지고, 다른 기기에서 삭제한 플러그인은 꺼집니다.
  - 모바일에서는 데스크톱 전용 플러그인을 켜지 않아요.

## ⏱️ 언제 동기화하나요?

따로 신경 쓰지 않아도 이런 순간에 알아서 동기화합니다.

- Obsidian을 **시작할 때**
- **주기적으로** (기본 5분마다)
- **편집을 멈추고** 잠시 지났을 때 (기본 30초)
- 다른 앱에 있다가 **Obsidian으로 돌아왔을 때**
- **네트워크가 다시 연결됐을 때**

다른 기기에서 바뀐 설정이나 플러그인이 내려오면, **다시 로드** 버튼이 있는 알림으로 알려드려요.

> [!TIP]
> **모바일 데이터도 아껴요.** 원격 파일 목록을 기기에 저장해 두고, 동기화할 때는 Google Drive 변경 기록에서 **바뀐 부분만** 받아옵니다. 바뀐 게 없으면 동기화 한 번에 작은 요청 하나(수백 바이트)면 충분해요. 하루에 한 번은 전체 목록을 다시 받아 혹시 모를 어긋남을 바로잡습니다.

## 🛡️ 내 노트는 안전한가요?

동기화 도구에서 가장 무서운 건 "노트가 사라지는 것"이죠. ObsiDrive는 데이터를 잃지 않는 것을 최우선으로 설계했습니다.

- **충돌이 나면 둘 다 보관해요** (기본값)<br>
  내 버전은 `노트 (conflict 2026-10-17 190233 Windows).md` 처럼 이름을 바꿔 남기고, 원격 버전을 원래 이름에 둡니다. 설정에서 "최근 수정본 / 항상 로컬 / 항상 원격"으로 바꿀 수도 있어요.
- **수정이 삭제를 이겨요**<br>
  한쪽에서 지우고 다른 쪽에서 고쳤다면, 고친 내용을 살립니다.
- **기준 상태가 없으면 절대 지우지 않아요**<br>
  상태 파일이 깨지거나 원격 볼트를 바꿔도 삭제는 일어나지 않습니다.
- **한꺼번에 많이 지워질 땐 먼저 물어봐요**<br>
  대량 삭제가 예정되면 확인을 받고, 자동 동기화는 잠시 멈춥니다.
- **원격 휴지통에 30일 보관** (설정 가능)<br>
  원격에서 지워진 파일은 `원격 휴지통에서 복원` 명령으로 되살릴 수 있어요. 로컬 삭제는 Obsidian의 휴지통 설정을 따릅니다.
- **동기화 중에 편집해도 괜찮아요**<br>
  덮어쓰거나 지우기 직전에 한 번 더 확인해서, 그 사이 편집한 파일은 다음 동기화로 넘깁니다.
- **새 기기가 기존 설정을 덮어쓰지 않아요**<br>
  설정 파일은 기본적으로 더 최근 수정본을 쓰지만, 기기가 처음 동기화할 때는 원격 설정을 우선합니다.

<details>
<summary><b>그 밖의 안전장치</b></summary>

<br>

- 업로드 직전에 원격이 바뀌지 않았는지 확인하는 **동시성 검사**
- 다운로드한 내용을 해시로 검증한 뒤에만 쓰는 **무결성 검사**
- **원격 중복 정리**, **대소문자 충돌 보호**
- **이름 변경 감지** — 큰 첨부파일을 옮겨도 다시 전송하지 않아요
- 네트워크 오류 시 **지수 백오프 재시도**

</details>

<details>
<summary><b>어떻게 바뀐 걸 알아내나요? (3-way 동기화)</b></summary>

<br>

각 기기는 "마지막 동기화 직후의 상태"(기준 상태)를 기억합니다. 동기화할 때 **로컬 · 원격 · 기준** 세 가지를 비교해서 어느 쪽이 바뀌었는지 판단해요.

| 로컬 | 원격 | 결과 |
|---|---|---|
| 변경 | 그대로 | ⬆️ 업로드 |
| 그대로 | 변경 | ⬇️ 다운로드 |
| 변경 | 변경 (내용 다름) | ⚠️ **충돌 처리** |
| 삭제 | 그대로 | 🗑️ 원격 삭제 (휴지통에 보관) |
| 그대로 | 삭제 | 🗑️ 로컬 휴지통으로 |
| 삭제 | 변경 | ⬇️ 다운로드 (**수정이 삭제를 이김**) |
| 변경 | 삭제 | ⬆️ 업로드 (**수정이 삭제를 이김**) |

변경 여부는 수정 시각과 크기로 먼저 거르고, 애매하면 **SHA-256 해시로 내용을 비교**합니다. 파일을 열기만 해서 시각만 바뀐 경우에는 전송하지 않아요.

</details>

## ⌨️ 명령어

명령 팔레트(`Ctrl/Cmd + P`)에서 `ObsiDrive`를 검색해 보세요.

| 명령 | 설명 |
|---|---|
| **지금 동기화** | 바로 동기화합니다. 리본 아이콘(↻)으로도 실행할 수 있어요. |
| **동기화 미리보기** | 아무것도 바꾸지 않고, 어떤 작업이 일어날지만 보여줍니다. |
| **동기화 로그 보기** | 최근 동기화 기록을 봅니다. 데스크톱에서는 상태 표시줄을 클릭해도 열려요. |
| **원격 휴지통에서 복원** | 원격에서 지워진 파일을 되살립니다. |
| **자동 동기화 일시정지/재개** | 자동 동기화를 잠시 멈추거나 다시 켭니다. |
| **진행 중인 동기화 취소** | 지금 돌고 있는 동기화를 멈춥니다. |
| **자가 진단: 노트 교체 시 바이트 보존 확인** | 이 기기에서 노트를 교체할 때 BOM·줄바꿈·한글·이모지 바이트가 그대로 유지되는지 확인합니다. 임시 노트는 동기화되지 않고 바로 지워져요. |

## 💡 알아두면 좋아요

- 숨김 앱 폴더도 **Google Drive 저장 용량에 포함**됩니다.
- **빈 폴더**는 동기화하지 않아요.
- 파일 내용을 **암호화하지는 않습니다**. 다만 숨김 앱 폴더에는 내가 만든 OAuth 클라이언트만 접근할 수 있어요.
- [remotely-save](https://github.com/remotely-save/remotely-save)를 참고해 설계했지만, 코드는 모두 새로 작성했습니다.

| 파일 | 역할 |
|---|---|
| `src/sync/planner.ts` | 순수 3-way 계획 함수 (I/O 없음) |

| `src/drive.ts` | Drive v3 클라이언트 (appDataFolder, multipart/resumable 업로드, 변경 기록, 재시도) |
| `src/remoteCache.ts` | 원격 목록 캐시 + 변경분만 받아오기 |
| `src/auth.ts` | OAuth PKCE (데스크톱 루프백 / 수동 붙여넣기) |
| `src/obsidianFs.ts` | Obsidian Vault/Adapter 연동 |
| `src/filter.ts` | 동기화 대상 판정 |
| `tests/` | 가짜 Drive · 파일시스템으로 두 기기 시나리오 · 경합 테스트 |
| `scripts/` | 빌드(`dist/`로 출력), 버전 올리기, 릴리스 스크립트 |
| `docs/` | GitHub Pages (홈페이지 · 개인정보처리방침) |

버그 제보나 제안은 [Issues](https://github.com/luminen529/obsidrive/issues)에 남겨 주세요. 🙌
