ObsiDrive

Obsidian 볼트를 본인 Google Drive의 숨김 앱 폴더로 동기화하는 개인용 플러그인
A personal Obsidian plugin that syncs a vault to a hidden app folder in your own Google Drive.

소스 코드 / Source code 개인정보처리방침 / Privacy Policy

무엇을 하나요? / What it does

  • 노트·첨부파일, Obsidian 설정, 테마, CSS 스니펫, 커뮤니티 플러그인을 여러 기기 사이에서 동기화합니다.
    Syncs notes, attachments, Obsidian settings, themes, CSS snippets and community plugins across devices.
  • 데이터는 Google Drive의 숨김 appDataFolder에만 저장되어 Drive 화면에 보이지 않습니다.
    Data is stored only in Google Drive's hidden appDataFolder and does not appear in your Drive.
  • Google 권한은 drive.appdata 하나만 요청합니다. Drive의 다른 파일은 읽거나 쓸 수 없습니다.
    It requests a single Google scope, drive.appdata, and cannot read or modify any other Drive files.
  • 중간 서버가 없습니다. 플러그인이 Google API와 직접 통신합니다.
    There is no intermediary server; the plugin talks to Google APIs directly.
이 앱은 개발자 본인의 개인 사용을 위한 것입니다. 각 사용자는 직접 만든 Google Cloud OAuth 클라이언트로 사용합니다.
This app is intended for the developer's personal use. Each user runs it with their own Google Cloud OAuth client.
